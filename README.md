# 🚀 Dewangga's Personal Portfolio

A modern, interactive, and fully responsive personal portfolio website built to showcase my journey as a full-stack developer. This repository contains the source code for my portfolio, highlighting my technical skills, featured projects, and experiences.

---

## 🛠️ Technologies Used (Tech Stack)

This project is built using modern web development tools to ensure high performance, SEO optimization, and a seamless user experience:

*   **Framework:** Next.js (React)
*   **Styling:** CSS Modules 
*   **Icons:** Devicon CDN & Custom SVGs
*   **Version Control:** Git & GitHub

---

## ✨ Key Features

*   **Dynamic Projects Showcase:** An interactive, smooth-scrolling projects section featuring detailed modals and a custom image lightbox for a premium viewing experience.
*   **Fully Responsive Design:** Optimized layouts that adapt beautifully across mobile, tablet, and desktop screens.
*   **Modern UI/UX:** A clean, dark-themed aesthetic with custom scrollbars, sophisticated hover effects, and staggered CSS animations.
*   **Integrated Contact Section:** Direct access to my professional networks, email, and a downloadable Curriculum Vitae.
